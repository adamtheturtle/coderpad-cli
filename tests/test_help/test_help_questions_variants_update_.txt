Usage: coderpad questions variants update [OPTIONS] QUESTION_ID VARIANT_ID

  Edit a variant, preserving omitted fields and explicit resets.

Options:
  --language TEXT            Language or project-template slug.
  --solution-file PATH       UTF-8 reference solution.
  --file PATH                UTF-8 starter code, including blank code.
  --directory PATH           UTF-8 project directory.
  --file-contents-json PATH  Structured project files with hidden/deleted flags.
  --reset-code               Restore single-file default code using explicit
                             null.
  --reset-project            Restore project template files using an empty list.
  --exclude TEXT             Additional directory Gitignore pattern. Repeatable.
  --dry-run                  Print a JSON plan without credentials or network
                             access.
  --help                     Show this message and exit.
