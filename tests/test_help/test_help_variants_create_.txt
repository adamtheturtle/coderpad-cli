Usage: coderpad questions variants create [OPTIONS] QUESTION_ID

  Create a variant and print its question and variant IDs as JSON.

  Omit --file and --directory to use default starter content. Save the returned
  variant ID for subsequent uploads. Each invocation creates a new variant;
  creation is never retried.

Options:
  --language TEXT   Language or project-template slug.  [required]
  --directory PATH  UTF-8 project directory to layer over the template.
  --file PATH       UTF-8 starter code file. An empty file creates blank code.
  --exclude TEXT    Additional Gitignore pattern at the upload root. Repeatable.
  --dry-run         Print a JSON plan without credentials or network access.
  --help            Show this message and exit.
