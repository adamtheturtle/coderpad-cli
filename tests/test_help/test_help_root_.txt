Usage: coderpad [OPTIONS] COMMAND [ARGS]...

  Manage starter code and inspect Interview and Screen resources.

Options:
  --version  Show the version and exit.
  --help     Show this message and exit.

Commands:
  questions  Manage question starter code and variants.
  screen     Inspect Screen using CODERPAD_SCREEN_API_KEY.
  user       Inspect the Interview API key owner.
