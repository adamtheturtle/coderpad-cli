Usage: coderpad questions variants [OPTIONS] COMMAND [ARGS]...

  Manage variants of an existing question.

Options:
  --help  Show this message and exit.

Commands:
  create  Create a variant and print its question and variant IDs as JSON.
  delete  Delete only this variant.
  get     Get one variant as JSON without changing it.
  list    List a question's variants as JSON, including template identity.
